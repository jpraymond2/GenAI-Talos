# Data layout

All committed datasets are **fictional**, created during the Open Agent Hackathon 2026. Do not treat names, companies, or messages as real people.

| Path | Role |
|---|---|
| `data/synthetic/` | **Primary demo** — Jordan Lefebvre / Tidepool world |
| `data/sample/` | **Unit-test fixture** only (Alex Martin, ~10 contacts) |
| `data/cache/` | Recorded LLM / web fixtures for zero-credential sample mode |
| `data/live/` | Live connector exports (**gitignored**) |
| `data/world_*.db` | Per-dataset World Model DBs (**gitignored** via `*.db`) |
| `data/identity_scores/`, `data/relationship_scores/` | Runtime score dumps (**gitignored**; keep `.gitkeep` only) |

---

## `data/synthetic/` (primary demo)

**Source.** Generated by `scripts/synthetic/make_synthetic.py` (default `--seed 20261026`). Raw exports under `raw/`; Recall’s four tables under `tables/`; answer key under `ground_truth/`.

**Licence / usage.** Fictional hackathon artifact. Safe to redistribute with the repo. Not for training claims about real individuals.

**Counts (approx.).** Owner Jordan Lefebvre; “now” Mon 26 Oct 2026 18:00 America/Toronto (`tables/dataset.json`). ~59 people in the answer key; ~2,900 messages (Gmail / iMessage / Messenger); ~175 calendar events; tables: contacts 42 (+header), events 176, handles 152, interactions 3006.

**Identity.** `identity_report.md` — 53/53 people sorted perfectly, 0 wrong merges (World Model ingest, no LLM).

**Answer key.** `ground_truth/people.json`, `facts.json` (41 facts), `fact_keywords.json`, `questions.json` (23 eval questions).

**Regenerate.**

```bash
uv run python scripts/synthetic/make_synthetic.py --out data/synthetic --seed 20261026
uv run python scripts/synthetic/raw_to_tables.py
uv run python scripts/synthetic/check_identity.py
```

Then `uv run python -m recall ingest --sample` (with `SAMPLE_DATA_DIR=data/synthetic/tables`).

**Limitations.** Deterministic filler banks repeat phrases; not a held-out privacy study. Eval questions were visible during development (see `output_examples/eval_report.md` Method).

## `data/sample/` (unit-test fixture)

**Source.** `scripts/make_sample_data.py` — small Alex Martin persona for fast pytest.

**Counts.** ~10 contacts, ~400 interactions, calendar slice; `dataset.json` sets `answer_key: null`.

**Usage.** `tests/conftest.py` pins `SAMPLE_DATA_DIR=data/sample`. Do not use as the judge demo (defaults point at synthetic).

**Regenerate.** `uv run python scripts/make_sample_data.py` (if present) or restore from git.

---

## `data/cache/`

Recorded responses for `SAMPLE_MODE` without NVIDIA / web keys: `llm/{router,writer,critic,default}.json`, web scout fixtures, etc. Keys are prompt hashes; agent roles no longer fall back to a global `"default"` brief. Safe to commit; contains no API secrets.
